Hardware SVG Icon Spec-Sheet

This document serves as the master style guide and component library for the industrial label generator icons.

AI Generation Guidelines

1. ViewBox: Always use viewBox="0 0 100 100".
2. Primary Color: Solid hardware bodies must use fill="#3b3b3b".
3. Cutouts & Transparency: Use fill="white" or stroke="white" to represent holes, drive recesses, threads, or cutouts. (The system relies on white acting as a transparent mask against white label backgrounds).
4. Perspective: Strictly 2D orthographic. Use pure Top-Down views for drive types/nuts/washers, and pure Side-Profiles for screws/bolts.
5. Style: Minimalist, bold, industrial, flat. No gradients, shadows, or complex perspective lines. Stroke widths should be bold (usually 4-6px).
